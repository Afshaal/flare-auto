# Flare Auto v1.2.1

Map packs release. The app is the same as v1.2.0 apart from the version number.

## Map packs

- **Lahore (r7):** map, 3D buildings, routing and search. Search adds Overture Places and pak-geodata area names;
  the pak-geodata entries are unverified and may be inaccurate.
- **Kuwait (r1):** map, 3D buildings, routing and search from OpenStreetMap.

Install: copy the pack ZIP to the head unit, then **Settings › Offline maps › Import navigation pack**.
Each pack includes `NOTICE.md` with its sources and licences.
