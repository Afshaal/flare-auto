# Decisions log

Ambiguous choices made during the optimisation / release-preparation pass, with the conservative option taken.

| ID | Decision | Why |
|---|---|---|
| D-01 | Work in `flare-auto-profiles-local/`, not `flare-auto-kotlin-6677f69/`. | The brief names the older snapshot, but all maps / widgets / profiles / routing work lives in `flare-auto-profiles-local/`. Confirmed by the owner before any change. |
| D-02 | Device measurements use only `install -r`, `am start`, `dumpsys`, `top`, `logcat`. The drawer jank run from the baseline (which used `adb shell input`) is not repeated. | Ground rule 6 lists the allowed adb commands; `input` and `push` are not on it. The exact commands are given in the report for the owner to run. |
| D-03 | ~~Baseline device numbers are the ones recorded by the previous session.~~ **Superseded by D-17.** | — |
| D-04 | Deleted `CustomizeActivity` and `DockEditorActivity`. | Declared but never launched by the release app (only a debug harness opened one); `GridEditorActivity` replaced both. Removing them removed most of the duplicated dock/split/`getChildAt` code. |
| D-05 | Item 16 (preview hack): only the static `HomeActivity.instance` remained; replaced by `HomeActivity.requestRebuild()` (a counter Home checks on resume). | The grid editor already rendered through a standalone `HomeCards` against a draft copy of the preferences. `prefs.clear()` does not notify listeners on API 28, so Settings › Reset needs an explicit signal. |
| D-06 | Kept a quirk: a saved dock without the drawer slot gets the five legacy slots appended. | Existing behaviour; pinned in `DockConfigTest` rather than "fixed". |
| D-07 | Pre-seeded drawer tiles (Files, Browser, stock head-unit screens, projection apps) are shown only when installed. | Requested in item 20. Identical on the Civic when those apps are present; previously a missing app showed a tile that only toasted an error. |
| D-08 | Screensaver vehicle label uses `letterSpacing = 0.25` for every name instead of the literal "C I V I C". | Requested in item 21; 0.25 em ≈ one Roboto space, so "CIVIC" looks the same. Custom names now get the same spacing. |
| D-09 | `simple-icons-index.json` kept next to `simple-icons-picker.json`. | It is not derivable: 140 of its 3,602 keys are aliases absent from the picker list. |
| D-10 | Kept one `allNetworks` call (in `StatusIcon.networkUp`) with a justified `@Suppress`. | Callback-only state would show "disconnected" for a moment on every Home rebuild; there is no synchronous replacement below API 31. |
| D-11 | Kept `Gravity.LEFT/RIGHT` (12 RtlHardcoded), `File.usableSpace` (3 UsableSpace), fixed landscape orientation and `getIdentifier` (DiscouragedApi). | START/END would mirror layouts under an RTL locale such as Urdu; `getAllocatableBytes` would change when map downloads are allowed; the unit is landscape-only; 3,470 icons are looked up by name. All would change behaviour. |
| D-12 | GraphHopper and Mapsforge are kept whole by R8 (`-keep`). | The router only runs with the navigation pack installed, so a shrinking mistake would show up first in the car. Library code around them is still shrunk (43,006 → 12,630 method references). |
| D-13 | `org.json` added as a **test-only** dependency. | `android.jar` ships stubs, so JSON code (dock migration, pack `build-info.json`) cannot be unit-tested otherwise. Not packaged in the APK. |
| D-14 | Navigation pack lives in `<external files>/navigation/<region>/`, verified against `checksums.txt` once and cached until files change. | Brief B9. The previous code unzipped `assets/maps/lahore-navigation.zip`, which never existed. |
| D-15 | The existing, unwired `OfflineGuidance` panel is shown on the full-screen offline map (`OfflineMapActivity`) only. | "Finish up to what the existing code clearly intends" without redesigning Home: the panel was written for a map host (`paintRoute`, `center`). |
| D-16 | Added debug-only `SmokeActivity` and `NavigationCheckActivity`; check harnesses also log to logcat. | Lets every screen and the navigation pack be checked with `am start` + `logcat` only (D-02). Not in release builds. |
| D-17 | Final device comparison is an A/B on the same emulator state (baseline APK then new APK, 7 cold starts each). | The earlier baseline was recorded in a different emulator state (profile prompt / process history), so comparing against it would mislead. |
| D-18 | Ran the debug `FeatureChecksActivity`, which creates and selects a "Feature test" profile, then its `cleanup` step. | The harness is part of the project's checks; `cleanup` restored the driver registry from its own backup afterwards. |
| D-19 | The Wagah regression trip starts 1.2 km before the border gate; a must-fail Attari case was added. | The original point snapped to the trunk road on the Indian side of the border barrier, which GraphHopper correctly never routes through. |
| D-20 | 3D map uses MapLibre Native **13.0.2, OpenGL ES variant** (`android-sdk-opengl`). | The default 13.x artifact requires Vulkan, which the Android 9 head unit may not have; the Civic reports OpenGL ES 3.2 (`ro.opengles.version` 196610), MapLibre needs 3.0. 13.0.2 is the newest release built with Kotlin 2.0, so the project's Kotlin 2.0.21 toolchain did not change. |
| D-21 | Vector tiles as **MBTiles** in the navigation pack, built by Planetiler with a small custom schema; local SDF glyphs generated from Noto fonts. | MBTiles local files have been supported since MapLibre Android 10; local PMTiles support is newer. MapLibre cannot read Mapsforge `.map`. A custom schema needs only the OSM extract (no water-polygon or Natural Earth downloads). |
| D-22 | Mapsforge stays as the second renderer: older packs, downloaded/imported `.map` regions, the world overview, the "3D vector map" switch, and automatic fallback when MapLibre cannot start (credit line shows the reason). | Replacing it outright would drop region downloads and break installs without pack r3. |
| D-23 | MapLibre renders into a TextureView; `android.useAndroidX=true`; native code limited to arm64-v8a (Civic) and x86_64 (BlueStacks). | TextureView respects the Home card's rounded clip and the grid's scaling (a SurfaceView would not). MapLibre depends on AndroidX. Other ABIs would add ~10–13 MB each with no target device. |
| D-24 | Two new preference keys, `offline_map_vector` (default true) and `offline_map_heading_up` (default true); no existing key changed. | Needed for the renderer switch and orientation mode; `KeysTest` updated deliberately. |
| D-25 | Heading-up uses the GPS bearing only at ≥ 2.5 m/s, otherwise the bearing of ≥ 12 m of movement, otherwise holds the last heading; eased 55 % per fix with a 3° dead band (`HeadingFilter`). | GPS bearings are noise when stopped or crawling; a parked car should not spin the map. |
| D-26 | Map UI r3: the turn card, trip card and status lines replace the old text panel on both the full map and the Home widget; both are driven by the same `OfflineGuidance` (widget: `compact`). "End" on the trip card stops navigation, the voice button mutes, the search button opens search. | Items 7–14 ask for one source of truth for widget and full map; the old panel's tap menu (search / stop / mute) became dedicated controls. |
| D-27 | Cards over the map use fixed night colours (near-black glass, dark-green turn card, white text) regardless of the launcher theme. | The MapLibre style is night-only (see MAPLIBRE-3D.md); theme-coloured cards would be unreadable on it in the light theme. |
| D-28 | Zoom: MapLibre max zoom 19.5 → 20.5; first follow settles at z17.4 (full map) / z16.9 (widget) instead of z16.5; Mapsforge max 19 → 20. Marker 44 dp → 32 dp with a larger arrow inside. | "CarPlay-style" closer view (item 4) and a smaller marker with a readable arrow (item 5). Tiles stop at z15 and over-zoom; vectors stay sharp. |
| D-29 | Attribution: full map has a 32 dp "i" button (bottom right) opening the attribution dialog; the widget shows a tiny "© OSM" mark; status messages (3D fallback reason, outside coverage) appear in a small top pill only while they apply. | Item 6: unobtrusive but still visible and one tap from the full "© OpenStreetMap contributors" text. The widget takes no touches, so it keeps a visible mark. |
| D-30 | Full map is edge to edge with square corners; a 48 dp back button sits top-left (system back works too); the turn card sits right of it. | Item 1; rounded card corners looked like a bug once the map filled the screen. |
| D-31 | Search screen is a full-screen `Dialog` (not an Activity); the keyboard is not opened automatically. | Keeps `OfflineGuidance.search()`/`choose()` unchanged in shape. Home/Work/Saved/Recent are the quick picks in a car; an auto-opened keyboard would cover them. |
| D-32 | Saved places: four new per-profile keys (`offline_places_starred`, `offline_places_recent` (8 max), `offline_place_home`, `offline_place_work`), JSON values. Home/Work are set by holding a result or saved place ("Set as Home / Work"). Recents are chosen destinations (not typed queries). | Owner decision (star + fixed Home/Work). Destinations are what a driver wants to repeat; typed fragments are not. |
| D-33 | Search DB schema 2 (pack revision 4, format still 1): extra columns `area`, `street`, `norm`, `osm`, a second FTS4 table `places_norm(norm)` and a `meta` table; `places`/`places_fts` unchanged so older apps keep working. `area` = nearest suburb/neighbourhood/quarter/village/town/hamlet node within 3 km. | Items 16–18 need a punctuation-free index and a place hint; a containing-polygon lookup would need area geometry processing for little gain. Older apps only query `places`(first five columns) and `places_fts`, which are unchanged; this app was tested with both the r3 and the r4 database. |
| D-34 | Ranking: text match class (exact / prefix / ordered word prefixes / any word prefixes / joined / other), then distance from the GPS fix (map centre without one), then name length. Candidates: 200 nearest matches + 200 shortest-name matches anywhere. Grouping: same OSM feature; or same normalized name within 500 m (1.5 km for two streets) when kinds match or one is generic (`place`, `street`); the specific row is shown. | Owner: "prioritize relevant nearby results"; streets are split into many OSM ways. Distinct same-name places further apart stay separate with their area and distance as the hint. |
| D-35 | Installed icons by default: drawer tiles for apps without a built-in glyph show the app's own icon (74 dp, no coloured tile, no tint); icon packs and imported images draw the same way. Built-in glyph tiles (stock head-unit screens and the `drawerStyle` system tools: Camera, Gallery, Wi-Fi, System settings, …) are unchanged. `dock_mono`, `icon_override_*` (Simple Icons choices) and `icon_color_*` are kept but no longer read. | Owner decision. Not renaming keys (ground rule); old Simple Icons choices fall back to the installed or pack icon automatically. |
| D-36 | Simple Icons removed completely (3,470 drawables, 4 assets, picker activity, `res/raw/keep.xml`, brand map, attribution file). `Credits` keeps the CarPlay / Android Auto trademark line and gains MapLibre/Noto. | Item 22. `keep.xml` only existed for the by-name `si_*` lookups (and its strict shrink mode); nothing else in the app is looked up by name. |
| D-37 | The redesigned round back button (drawn chevron in a 44 dp circle) is used by every `UiKit.header` screen; only the app drawer drops the Home button and sets the back button flush with its page padding. | Item 23/24 target the drawer; one back-button style across screens is more consistent than a drawer-only variant. Other screens keep their Home button. |
| D-38 | Offline Maps settings reduced to 8 rows: enable, navigation pack (status), 3D map, orientation, follow GPS, map center (one list: automatic / GPS / coordinates), view span, "Other regions" (catalog, URL, download, import, remove — or cancel a running download — in one list). Removed rows: "Use current GPS position" (merged), "Map card size" (Home editor), "Map storage", "Download status" (shown as the Other regions value), "Map credits" (map "i" button + About credits). | Item 19: keep every control, drop duplicated information. |
| D-39 | Settings values: display text is mapped from stored values ("dark" → "Dark", "left" → "Top left", "1 days" → "1 day", "0 hidden" → "None hidden"); nothing stored changes. | Item 25. |
| D-40 | Screensaver 15 s / 30 s: new key `saver_timeout_seconds` (15 or 30) wins when > 0; choosing it also stores `saver_timeout` = 1, choosing a minute option removes the seconds key. | Item 26: minute values keep their meaning; an older 1.2.0 build swapped in over this one falls back to 1 minute rather than "Off". |
| D-41 | Profile picker: every item (profiles and Add New) is the same width (avatar + 36 dp) with the icon over a 40 dp label slot; Add New draws a plus-in-circle at avatar size. The row is centred (`fillViewport`) and scrolls sideways when it does not fit (4 items fit at 1280×720). | Item 27. |
| D-42 | Turn arrows are drawn from the GraphHopper sign (`TurnArrow`); `NavStep` gained an optional `road` (instruction street name; falls back to the instruction text). | Item 7; the sign was already in `NavStep`, the street name was not. |
