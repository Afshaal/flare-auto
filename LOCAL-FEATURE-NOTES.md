# Local driver/grid/screensaver build

Not published. Package, version, signing configuration and minimum Android version unchanged.

- Startup > Driver profiles: floating, dimmed Guest/Family chooser with generated smile avatars. Family uses the existing default settings; Guest uses separate persistent settings. Choose Ask/Last/Family startup behavior. Long-press Home date to open the popup. Existing custom profile data remains stored but is not listed in the two-choice popup.
- Default driver uses existing home preferences and image files. New drivers start with independent defaults. Android permissions, installed apps, update checking, forecast cache and device startup bookkeeping stay shared.
- Personalization > Customize home screen: 8x6 grid, snap movement, lower-right resize handles, tap to change/remove cards, Undo/Cancel/Save. Type-specific minimum sizes allow three or more widgets. Standard clock and media cards retain controls when shortened; content scales to fit. Short media uses a horizontal artwork/control layout; full-size media uses larger artwork and smaller metadata text. Separate classic/minimal clock cards intentionally omit projection controls; a standalone CarPlay/Android Auto widget is available. Four red corner handles resize; hold to move; swipe to change pages.
- Swipe either direction in the editor to a finite end panel, then tap the large translucent plus to insert a page at that end. Maximum five pages; no wraparound or automatic page creation. Page options includes a three-card preset, delete/reorder/default and restore-legacy actions. Home and editor transitions follow the drawer slide/fade easing and timing. Home dock/status remain fixed; only active page widgets run live. Application widgets have a dedicated add/remove editor and working launch shortcuts (up to eight, shared within a profile).
- Appearance controls inside the editor open the existing editor for vehicle/corner/dock settings; those controls retain their existing immediate-save behavior. Grid/page edits remain drafts until Save. Undo history is session-local; draft/pages survive activity recreation.
- Screensaver: weather, next solar event, optional information over image mode; reuses existing opt-in weather/cache/location logic, no new requests or services. Weather falls back to solar information when no permitted/usable forecast exists.
- Notification banners: off by default per driver; allowlist of launchable apps; hidden content by default; duration 2-15 seconds, size 85-120%. Top-left by default, with top-right or alternate-corner selection; no action buttons; one at a time, three pending entries, coalesces repeated notification keys. Swipe dismiss; tap opens the notification action when available. Expiry keeps screensaver open. Secret, ongoing and group-summary notifications are excluded. Requires existing notification-listener access; does not import iPhone notifications.
- Startup picker is based on Android boot ID, not ACC/deep-sleep wake. No vehicle-gear detection. Profiles are preference separation, not an Android security boundary. Switching drivers does not change Bluetooth pairing or OEM routes.

Device verification: test the picker on a genuine full boot; all card sizes at Civic density/text scales; page swipes versus seek gestures; notification availability and actions from actual head-unit apps; screensaver timeout/exit and weather expiry offline. No Civic install performed.
